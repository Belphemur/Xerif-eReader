## Adding a record

1. Name it `YYYY-MM-DD-topic.md` (the date is the identity and the
   index sort key).
2. Carry a Status line in the first 3000 chars so the index buckets it:
   `Status: Draft for owner review`, `Status: Accepted — implemented in
   PR #N`, `Status: SUPERSEDED by <file>`.
3. If it supersedes one, flip the old record's Status to SUPERSEDED by
   the new file in the same commit.
4. Regenerate the index and commit it in the same change.
5. Nothing else — `AGENTS.md` links here.
