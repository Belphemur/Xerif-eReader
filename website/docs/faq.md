# FAQ

## Will I lose my books and settings?

No. Xerif keeps the books, fonts, dictionaries, and settings already on
your SD card. Web flashing touches only the system area.

## Can I go back to the stock firmware?

Yes — see [Restore stock Xteink firmware](/flash#restore-stock-xteink-firmware)
on the Flash page.

## Does it need Wi-Fi?

Only for wireless features: web file transfer, OPDS catalogs, OTA
updates, and progress sync. Reading works entirely offline.

## Which book formats work?

EPUB, TXT, and Markdown. PDF, MOBI, AZW3, and CBZ are not supported —
convert them to EPUB first.

## X3 owner — what should I run?

Xerif needs memory the X3 doesn't have. Use
[CrossPoint](https://github.com/crosspoint-reader/crosspoint-reader),
which supports the X3.

## Is Xerif free?

Yes — free and open source under an open license, maintained by the
community. It builds on CrossPoint; please
[support CrossPoint](https://app.royalty.dev/crosspoint-reader/crosspoint-reader)
if you find it useful.

## How do I report a problem?

Check [Troubleshooting](/docs/troubleshooting) first, then search or open
an issue on [GitHub](https://github.com/Belphemur/Xerif-eReader/issues).
