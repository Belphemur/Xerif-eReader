# Xerif documentation

Short, practical guides for everyday use. For developer documentation,
design notes, and contribution workflows, see the
[GitHub repository](https://github.com/Belphemur/Xerif-eReader).

**Getting started** — install Xerif, set it up for the first time, load your
books, and keep it updated.

**Features** — what the reading experience offers: typography, images,
sync, fonts, sleep screens, the web interface, and plugins.

**Reference** — supported devices, button and touch controls, and what to
do when something misbehaves.
