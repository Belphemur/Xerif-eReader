# Web interface

The reader runs a small web server you can reach from any browser on the
same network — for moving books around and changing settings.

## Start it

1. Open **File Transfer** on the reader.
2. Pick **Join a Network** (your Wi-Fi), **Calibre Wireless**, or
   **Create Hotspot** (the reader becomes its own network).
3. Open the address shown on the reader screen — typically
   `http://<device-ip>` or `http://xerif.local`.

## What it can do

- Upload, download, rename, move, and delete files; create folders.
- Download books and screenshots back off the device.
- Edit most device settings from the browser.
- Manage saved Wi-Fi networks and OPDS servers.
- Upload font families to the SD card.
- **WebDAV:** mount the reader as a network drive from your computer's
  file manager.
- **Calibre wireless:** receive books from Calibre's wireless workflow.

## Privacy note

The web server has no password. Use it on networks you trust, or in
hotspot mode where you control who connects.
