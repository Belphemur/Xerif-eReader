# Loading books

## Formats

| Format | Works? |
| --- | --- |
| EPUB | Yes — the main format, fully rendered |
| TXT, Markdown | Yes |
| PDF, MOBI, AZW3, CBZ | Not supported |

Prefer EPUB for typesetting quality. Books already on the SD card from the
stock system or CrossPoint keep working.

## Ways to add books

**USB drive (no Wi-Fi):** open **File Transfer** on the reader and pick the
USB option — the SD card appears as a drive on your computer. Copy books
into any folder and eject safely.

**Web browser over Wi-Fi:** open **File Transfer → Join a Network**, then
browse to the address shown on screen. Upload, download, and organize files
from the browser. See [Web interface](/docs/web-interface).

**Calibre wireless:** the built-in Calibre Wireless mode accepts books from
Calibre's wireless plugin workflow.

**OPDS catalogs:** add a catalog server (Calibre-Web, Project Gutenberg, …)
under **Settings › OPDS Servers** and download straight to the device.

## If a book renders oddly

Some EPUBs carry unusual stylesheets. Run the built-in **EPUB Optimizer**
from the device — it cleans up and reprocesses the book for better
rendering, without touching your original file elsewhere.
